STARFUL CLOTHING — STORE WEBSITE

Included:
- Responsive storefront
- STARFUL logo
- Product cards for tee, hoodie, and cap
- Size selectors
- Working browser shopping cart
- Quantity controls
- Checkout/customer-information screen
- STARFULCLOTHING.BRAND branding

IMPORTANT:
The checkout included here is a working DEMO checkout. It does not process real credit cards or collect/store payment information.
To launch a real store, connect the checkout to a payment provider (such as Stripe) and a secure server/database, then configure shipping, taxes, inventory, and order emails.

DOMAIN:
The text STARFULCLOTHING.BRAND is included in the site. You still need to register the domain if it is available.
